# Database Design

## Database Name

hr_analytics

---

## Database Structure

The HR Analytics project uses a **single-table database design**.

### employees

This table stores all employee-related information from the IBM HR Analytics dataset.

Primary Key:
- EmployeeNumber

Total Columns:
- 35

---

## Design Choice

This project follows a single-table analytical database design because the primary goal is data analysis, dashboard creation, and machine learning rather than transaction processing.

This design simplifies:
- SQL Analysis
- Power BI Dashboard Development
- Python Data Analysis
- Machine Learning
